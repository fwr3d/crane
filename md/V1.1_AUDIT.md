## Immediate gaps to close before v1.1 ships

1. **Wire `Stats.tsx` and `Account.tsx` into nav** — both pages are fully built but unreachable. Add them to the `NAV` array in `App.tsx` and update the `Page` type.
2. **Expose `sources.py` scrapers via API + Find UI** — `fetch_remoteok`, `fetch_yc`, `fetch_greenhouse`, `fetch_lever` exist but the Find page only calls LinkedIn. Need API endpoints + UI source selector.
3. **Surface dark mode toggle** — `useDarkMode` hook is ready; just needs a button in Account or sidebar footer.
4. **Mobile sidebar** — swap fixed 220px sidebar for a hamburger menu below breakpoint.
5. **Add `source` field to DB schema** — prerequisite for source-based analytics and the "track application source" feature.
